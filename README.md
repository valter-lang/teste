# 📦 Sistema de Equipamentos em Campo

Dashboard para gerenciamento de equipamentos instalados em clientes e lojas, com integração ao Supabase.

## 🚀 Deploy

Este projeto está configurado para deploy no Vercel.

## 📊 Funcionalidades

- Dashboard com KPIs em tempo real
- Visualização por região, status e vendedor
- Integração com Supabase para dados reais
- Interface responsiva e moderna

## 🔧 Tecnologias

- HTML5, CSS3, JavaScript
- Supabase (Backend)
- Fetch API para requisições

## 📝 Configuração

As credenciais do Supabase estão configuradas em `supabase-client.js`.
